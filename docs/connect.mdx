Leave the `Authorization` header out if your client supports the browser
sign-in — it gets a refreshable token that way. Otherwise mint an API key with
the `mcp` and `read` scopes, and add `scans:write` if the agent should also be
able to launch scans. The
[companion CLI](/account/cli-and-device-login) registers the server with the
clients it can detect.
